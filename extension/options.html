GitHub 저장소 (권장)

주소만 넣고 연결을 누르면 저장소 확인 → Aside 계정 고정 → 자동 동기화 등록 → 첫 동기화까지 한 번에 합니다. 반드시 비공개(Private) 저장소를 쓰세요 (채팅 원문이 올라갑니다). 이 PC에서 git으로 그 저장소에 접근할 수 있어야 합니다.

GitHub 로그인이 필요합니다
이 PC의 git에 저장소 접근 권한이 없습니다. 이 저장소만 쓸 수 있는 토큰을 만들어 붙여넣으세요.
  1. 토큰 만들기 페이지 열기 (이름·기간·Contents 쓰기 권한이 미리 채워집니다)
  2. Repository access → Only select repositories → 저장소 선택
  3. Generate token을 누르고 표시된 토큰(github_pat_...)을 복사
토큰은 이 PC의 키체인(Windows: 자격 증명 관리자)에 이 저장소 전용으로 저장되고, 설정 파일·로그·저장소에는 남지 않습니다. 다른 GitHub 로그인에는 영향이 없습니다.
